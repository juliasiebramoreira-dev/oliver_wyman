# Real Estate Loan Risk Analysis Case
This project provides a comprehensive risk assessment for a loan portfolio, using financial metrics and Machine Learning to predict default probabilities.

## 🚀 Key Features
*   **Data Cleaning:** Robust preprocessing of financial data (currency, percentages, and formatting).
*   **Financial Metrics:** Calculation of **LTV** (Loan-to-Value) and **DSCR** (Debt Service Coverage Ratio).
*   **Predictive Modeling:** Implementation of a **Logistic Regression** model to estimate the probability of default.
*   **Risk Categorization:** Automated "Flag" system (Red, Yellow, Green) based on critical financial thresholds.
*   **Visual Matrix:** Generation of a risk heatmap by Region and Property Class.

## 🛠️ Technologies Used
*   **Python 3.x**
*   **Pandas & Numpy** (Data Manipulation)
*   **Scikit-Learn** (Machine Learning)
*   **Regex** (String Cleaning)
